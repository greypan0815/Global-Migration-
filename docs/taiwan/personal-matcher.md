## 不同國家的積分不是同一回事

| 國家與路線 | 正式制度 | 本站作法 |
|---|---|---|
| 加拿大 Express Entry | CRS 按政府規則排名 | [IRCC 官方計分器](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/express-entry/check-score.html)，本站只提示工作經驗與語言缺口 |
| 澳洲 189 | SkillSelect 積分制，最低 65 分只是獲邀必要條件之一 | 已填且已證明的部分積分小計；[官方積分表](https://immi.homeaffairs.gov.au/supporting/Pages/Work/189-points-table.aspx) |
| 紐西蘭 SMC | 六分制、技術工作經驗或技工／技術人員等路徑 | 核對工作與資格線索，[官方 SMC](https://www.immigration.govt.nz/visas/skilled-migrant-category-resident-visa/) |
| 德國 Chancenkarte | 有免積分的資格認定路徑，另有六分制 | 官方資格說明，不自行核算法定六分 |
| 英國 Skilled Worker | **法定 70 分資格制**，含雇主、職位、語言及薪資 | 依必要條件檢查，**不是分數越高越能獲邀** |
| 德國藍卡／荷蘭 HSM／愛爾蘭 CSEP | 合格雇主、薪資、專業及居留要求 | 可改善的條件缺口，不假裝計算競爭積分 |
| 加拿大 IEC／英國 YMS／打工度假 | 申請資格、窗口、抽選或名額 | 年齡、戶籍、工作權及季節限制 |

**重要日期**：IRCC 已公告 2026 年 11 月 3 日將調整部分 CRS 計分規則。本工具刻意不複製整套 CRS 公式，避免在變更後仍顯示過時分數。

## 「條件準備度」的計算方式

這個問卷有 **24 條具路線專屬檢查清單**，包括年齡、工作機會、職業、雇主擔保、薪資、學經歷、語言、目標及短期簽證限制。每一項區分：

- **已具備**：使用者聲明符合初步條件，仍需要正式證明。
- **需要準備**：尚未有合格 offer、薪資或其他條件，不等於永遠失格。
- **尚未確認**：未提供資訊，不會假設已符合。
- **目前已知不符**：明確硬性條件不符合（例如超過年齡上限、無要求的臺灣戶籍），排在其他選項後面。

顯示的 0–100 **不是成功率**。其計算方式為：

**條件準備度 = 已具備的條件權重總和 ÷ 該路線所有檢查條件的權重總和 × 100，四捨五入。**

權重是本網站的研究整理方法，不是政府法律公式。未知項目不會算成已符合；結果可隨欄位輸入更新。符合初步條件也不表示實際有合法工作權、一定得到邀請或符合所有移民資格。

既有資料庫共 150 條路線。這版針對 **24 條**提供初步分析；另外 **126 條**仍可在原版網站研究，**不代表不適用臺灣**。目前政策來源僅對 **22 條部分欄位**進行官方核查，請依路線的政府資料連結核對。

## 澳洲 189 部分積分示例

依官方 Points Test，使用者可以自願提供已可證明的項目：

| 項目 | 官方基本級距 |
|---|---|
| 年齡 | 18–24：25 分；25–32：30 分；33–39：25 分；40–44：15 分 |
| 認可英文等級 | Competent：0；Proficient：10；Superior：20 |
| 已認可最高學歷 | 合格 Diploma：10；Bachelor／Master：15；Doctorate：20 |
| 合格海外年資 | 3／5／8 年：5／10／15 分 |
| 合格澳洲年資 | 1／3／5／8 年：5／10／15／20 分；**海內外合計最多 20 分** |
| 配偶／單身 | 依實際合法資格可為 0、5、10 分 |

本站僅列出已輸入且使用者**明確選擇有正式證明**的項目小計，尚未納入澳洲學習、偏遠地區學習、Professional Year、NAATI 社區語言等項目。就算小計達 65 分，仍可能欠缺技能評估、合格職業、正式英文證明、EOI 與名額，也不保證獲邀或獲批。

完整表格：[澳洲內政部官方 189 Points Table](https://immi.homeaffairs.gov.au/supporting/Pages/Work/189-points-table.aspx)。

## 隱私及限制

- 所有填寫內容在瀏覽器執行，不會向伺服器送出；只讀取不包含個資的公開靜態資料。
- 問卷不使用 localStorage、sessionStorage、cookies 或 URL 參數儲存年齡、收入及學經歷。
- 不會用自評英文自動推導澳洲或加拿大的合法語言考試分數。
- 未填寫條件、國籍、戶籍、學歷認定、薪資例外、工作地、配偶及稅務等，仍可能改變正式資格。
- 2026 年門檻、申請季及分數可能在申請前變動。請以各國官方當期規則為準。

本工具以臺灣護照研究為主，不提供簽證保證與法律意見。
