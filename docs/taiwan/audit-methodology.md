# 全球移居資料的官方驗證方法

**政策核查基準：2026-10-30；美國 DV／J-1 另於 2026-10-31 增補核對**　｜　[台灣專區](README.md)　｜　[互動網站](../../README.zh-TW.md)

## 核對什麼、不核對什麼？

本站仍顯示上游原始 99 條歐洲路線、11 條歐洲補充路線、33 條全球路線與 9 條台灣補充路線（合計 152），**不代表 152 條內容全部正確且可受理**。本次額外整理的 `data/policy_reviews.json` 針對 **24 條優先路線**的**特定政策欄位**，以官方一手來源核對；其他 **128 條**維持上游參考資料，不宣稱完成官方稽核。網站的臺灣明確適用資格數為 **10 條**（原有 9 條，加上捷克 Digital Nomad Program），這也**不代表**其他 142 條不適用台灣。

每筆優先路線拆成：

1. `passport`：台灣是否被點名適用、一般第三國資格，或須依**出生地／chargeability**判斷。
2. `window`：當年度是否停止受理、是否有抽選窗口或優先日期，別把上游 `open` 當即時狀態。
3. `work`：是開放式、指定雇主、遠距限制、實習，還是申請移民的制度而**不是工簽**。
4. `settlement`：PR／永居的資格與另外申請程序；清楚標示**Stamp 4、Resident Visa、工作居留**不是同一身分。

**每筆只保證「reviewedFields」中註明的特定欄位經官方頁面比對**；並提供核對日期、政策生效日（如有）和來源。未核對的上游細節不應和政府已核對的數字混在一起。

## 來源品質分級

| 等級 | 定義 | 應如何使用 |
|---|---|---|
| 部分欄位經官方核對 | 該筆有政策查核紀錄、具體政府來源、明列核對欄位及日期 | 可作為研究起點，但遞交前仍須查當期政策 |
| 有官方連結、未逐條核對 | 原版資料含官方連結，但不表示所有資格、門檻、受理日期已一一確認 | 只能當索引，不保證當前正確 |
| 僅國家層級官方入口 | 如全球部分頁面僅有移民局首頁，未直接佐證該簽證的每個欄位 | 請自行尋找更精準的官方路線頁 |
| 僅第三方來源 | 商業移民網站／律師整理；可能有廣告或過時內容 | 須回到政府頁核對 |
| 缺少路線直接來源 | 找不到路線專屬來源 | 不應直接依它作高成本決策 |

## 政策時點與申請決策

- **政策核查日**是研究人員看到官方頁面／比對的時間，**政策生效日**是規定真正開始適用的時間；兩者不能混用。
- **當年度申請季**是獨立維度：加拿大 IEC 2026 年候選人池已關閉，但已獲 ITA 的人仍可在期限內申請；這不代表 2027 制度取消。
- **月度排期**要寫清月份與 Final Action／Dates for Filing 的差別。2026 年 11 月的美國排期不能當 2026 年 10 月的核發時間。
- **薪資門檻**每年調整；荷蘭、德國、澳洲、英國等應按職類與有效日期計算。門檻符合並不保證雇主擔保、簽證或 PR 核准。
- **台灣護照與戶籍／出生地**有別。某些打工度假另須臺灣戶籍證明，美國移民排期常依法定出生地歸屬。

## 維護規則

資料來源位於：
- `data/policy_reviews.json`：官方欄位核查，依 `tw:`、`eu:`、`extra:`、`global:` 等路線 ID 對照。
- `data/taiwan_applicability.csv`：台灣明確適用簽證的原始摘要；其中 2026 關閉窗口亦須同步更新。
- `data/programmes.json`、`src/global.json`、`src/extra_routes.json`：上游較廣的國家路線（未全面查核）。
- `scripts/build_site.mjs`：產出前端 `dist/data/catalog.json` 的建置程式。

每次調整政策必須附上政府網址、核查日與**究竟核查哪些欄位**；若來源互相衝突，請標記「待查」，不要自行選擇比較樂觀的說法。不能為了增加「已核對」數量，將一般第三國工作制度當成政府已明確核定每一位台灣人的個案資格。

## 本次仍未解決的問題

- 原有 128 條路線的所有政策細節、費用、受理狀態和台灣護照資格仍待個別驗證。
- 無法從原始資料推導每條簽證的申請成功率或移民所需總成本。
- 從台灣遠距受僱於海外公司／EOR，涉及實際工作所在地及當地勞動、移民與稅務規範，不能把任何數位遊牧簽證當成全球合法就業許可。
- Cloudflare 正式環境與 GitHub 最新建置可能有短暫差異；以站台實際載入的版本與 CI／部署記錄為準。

此專案不是移民代辦，不提供保證錄取或法律意見。完整政府網址在每條已核對路線的明細中。
