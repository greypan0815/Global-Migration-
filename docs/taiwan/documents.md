## 首先確認護照與戶籍

臺灣護照、戶籍、國籍與簽證計畫的適用資格可能是不同問題。有些簽證另要求戶籍或排除特定護照種類。例如 [紐西蘭 Taiwan Working Holiday Visa](https://www.immigration.govt.nz/visas/taiwan-working-holiday-visa/) 要求**臺灣護照 + 臺灣戶籍證明**。持臺灣護照但無戶籍者，不應直接假設符合所有臺灣特殊名額。

## 準備工作表

| 類別 | 臺灣常見文件 | 必須確認 |
|---|---|---|
| 身分 | 護照、身分證、戶籍謄本 | 護照種類、效期、戶籍及出生地 |
| 學歷 | 學位證書、成績單、英文證明 | 當地是否需 ECA 或指定學歷認證 |
| 工作 | 英文在職／離職證明、勞動契約、薪資單、薪資及投保紀錄 | 職責、時數、起訖日期、雇主與職類是否符合 |
| 民事 | 出生、婚姻、親屬證明 | 家屬條件及認證譯本 |
| 良民證 | 臺灣警察刑事紀錄證明、其他居住國證明 | 期限、停留史及翻譯／驗證規定 |
| 財力 | 銀行存款與交易紀錄、薪資及所得資料 | 幣別、持有期間與資金來源 |
| 其他 | 醫療保險、體檢、雇主 offer、照片 | 依各簽證類別而定 |

## 公證、文件驗證、翻譯

原版中國大陸文件指南提及**中國大陸 Apostille、學信網、公安無犯罪記錄與外匯額度**，這些**不是臺灣文件的通用程序**。

臺灣外交部領事事務局說明：文件是否需要認證或驗證，取決於**接收機關**的要求；應先向要證機關確認所需文件及應辦理的公認證／驗證程序，再準備文件。見 [外交部領事事務局官方說明](https://www.boca.gov.tw/cp-43-316-d63e2-1.html)。

## 建議順序

1. 先確認自己**護照／戶籍資格**符合預定計畫，並下載官方最新申請清單。
2. 記錄文件簽發地、有效期、語言、驗證機構與申請截止日。
3. 提前向學校與雇主申請英文證明，核對所有姓名拼寫一致。
4. 按目的國要求準備良民證、公證、譯本、驗證及 ECA，避免文件過期。
5. 保存官方申請資料、錄取或聘僱文件、有效簽證及合法工作期間證據。
6. 若目標是 PR／國籍，另外檢查真正的長期居留與入籍要求。
