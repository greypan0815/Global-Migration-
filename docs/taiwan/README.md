## 二、直接找工作與長期移民要分開看

短期打工度假和永久居留（PR）是不同制度。若目標是不讀碩士、直接到海外擔任正式軟體工程師，可並行研究：

- **加拿大**：合格 IEC／其他工作許可 → 加拿大合格工作經驗 → CEC 或 PNP → Express Entry 與 PR 審查；**每一階段都不保證成功**。詳見 [加拿大 IEC 專頁](canada-iec.md)。
- **德國、愛爾蘭、日本、美國等**：雇主聘僱及工作居留制度；原版各國資料可作為研究索引，但尚未完成臺灣護照逐路線驗證。
- **全球遠距工作**：數位遊牧簽證和合法在當地就業不同，需同時確認僱傭關係、稅務、居留延長及是否能累積 PR 年限。

## 三、原版中國大陸專屬資訊不能直接套用

| 原版敘述 | 臺灣讀者需要的修正 |
|---|---|
| 中國大陸護照不適用 | **不代表臺灣也不適用**，例如美國 E-2、加拿大 IEC、英國 YMS |
| 中國大陸無法雙重國籍 | 不能當成臺灣國籍法的結論；應另查國籍取得／喪失規定 |
| 美國「中國出生 EB-2 排期」 | 職業移民排期常涉及**出生地／chargeability**，不是僅憑護照判定 |
| 奧地利 21 個月取得永居 | 21 個月轉 Red-White-Red Card Plus **不是永久居留** |
| 中國大陸 Apostille、學信網與文件驗證 | 臺灣有自己的文件簽發與驗證體系，見 [臺灣文件指南](documents.md) |

## 四、資料狀態與讀者責任

- **official_checked**：只表示特定「臺灣屬計畫適用對象」與註明的限制有官方來源。
